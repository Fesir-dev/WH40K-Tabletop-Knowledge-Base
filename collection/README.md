# Physical collection

This domain describes what the user physically owns.

It is deliberately separate from current game points and rules.

## What belongs here

- physical bodies/models;
- built vs on-sprue state;
- magnetization;
- interchangeable unit roles;
- weapon/arm/bit pools;
- mutually exclusive configurations;
- shared Imperium models;
- unresolved physical-count questions.

## What does not belong here as authority

- current points;
- current datasheet legality;
- current detachment legality;
- current balance status.

Historical roster point values may be retained only as explicitly dated snapshots.

## First imported collection

`adeptus_custodes/` is the first canonical collection domain, migrated from the 2026-07-11 v0.5 provisional inventory.
