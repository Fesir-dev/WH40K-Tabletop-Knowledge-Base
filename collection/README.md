# Physical collection

This domain describes what the user physically owns.

It is deliberately separate from current game points and rules.

## What belongs here

- physical bodies/models;
- built vs on-sprue state;
- magnetization;
- interchangeable unit roles;
- weapon/arm/bit pools;
- mutually exclusive configurations;
- shared Imperium models;
- unresolved physical-count questions.

## What does not belong here as authority

- current points;
- current datasheet legality;
- current detachment legality;
- current balance status.

Historical roster point values may be retained only as explicitly dated snapshots.

## Canonical collection domains

- `adeptus_custodes/` — migrated from the 2026-07-11 v0.5 provisional inventory.
- `thousand_sons/` — user-supplied New Recruit physical collection export, normalized 2026-09-30.
- `world_eaters/` — World Eaters portion of the mixed World Eaters/Khorne export, normalized 2026-09-30.
- `chaos_daemons/` — Khorne and Tzeentch daemon physical collection pools, normalized 2026-09-30.

All newly imported Chaos-side inventories are `PROVISIONAL` until build state, magnetization, shared-body identities and loose component pools are physically reconciled.

Raw New Recruit exports are not vendored when they contain extensive copyrighted rules text. Store normalized physical facts plus provenance hashes instead.
