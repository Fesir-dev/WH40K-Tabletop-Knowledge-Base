# Physical collection

This domain describes what the user physically owns.

It is deliberately separate from current game points and rules.

## What belongs here

- physical bodies/models;
- built vs on-sprue state;
- magnetization;
- interchangeable unit roles;
- weapon/arm/bit pools;
- mutually exclusive configurations;
- shared Imperium models;
- unresolved physical-count questions.

## What does not belong here as authority

- current points;
- current datasheet legality;
- current detachment legality;
- current balance status.

Historical roster point values may be retained only as explicitly dated snapshots.

## Canonical collection domains

- `adeptus_custodes/` — migrated from the 2026-07-11 v0.5 provisional inventory.
- `thousand_sons/` — user-supplied New Recruit physical collection export, normalized 2026-09-30.
- `world_eaters/` — World Eaters portion of the mixed World Eaters/Khorne export, normalized 2026-09-30.
- `chaos_daemons/` — Khorne, Tzeentch, Slaanesh and Undivided daemon physical collection pools, normalized/reconciled incrementally on 2026-09-30.
- `adeptus_mechanicus/` — reconciled 121-model physical collection, closed 2026-09-30 with magnetization/loadout constraints recorded.
- `imperial_knights/` — 4-model direct-confirmation baseline: 2 fully magnetized Armiger chassis + 2 magnetized Questoris-scale chassis with shared component pools.

All newly imported Chaos-side inventories are `PROVISIONAL` until remaining build state, magnetization and loose component pools are physically reconciled. The previously suspected Daemon Prince shared-body overlap was resolved by user confirmation on 2026-09-30: five distinct Daemon Prince physical models are confirmed across the World Eaters and Chaos Daemons domains.

Raw New Recruit exports are not vendored when they contain extensive copyrighted rules text. Store normalized physical facts plus provenance hashes instead.

Adeptus Mechanicus physical reconciliation is closed at 121 models. Imperial Knights are tracked by shared physical chassis so magnetized alternate roles cannot be double-counted.
