# Shared Chaos collection

Checkpoint: **2026-09-30**  
Status: **PROVISIONAL**

Canonical inventory: `current.json`.

This domain stores physical Chaos models that are genuinely shared between multiple faction collections and therefore must not be duplicated inside each faction inventory.

## Chaos Spawn

Exact physical pool: **10 models**.

Visual styling:

- Khorne-styled — **1**
- Tzeentch-styled — **2**
- universal/generic Chaos — **7**

These are ten bodies total, not ten per faction.

The same pool can supply Chaos Spawn roles to different Chaos armies where the current rules allow that datasheet. Allocation is exclusive at the physical level: a model used in one simultaneous roster cannot also instantiate a second roster.

Styling is not a faction lock. The visual theme is preserved as hobby information while physical ownership remains global.

## Historical roster correction

The World Eaters collection export selected six Chaos Spawn. That was a roster allocation from this shared pool, not evidence of six separate World Eaters-owned models.

Faction inventories now reference this canonical shared pool instead of owning duplicate Spawn bodies.
