## Scope and accounting rules

This collection has been accumulated since approximately 2013 across multiple editions. Physical ownership is therefore tracked independently from current roster legality.

Order of reconciliation:

1. physical bodies/models;
2. assembled / unfinished / on-sprue state;
3. fixed or magnetized loadouts;
4. loose bits and conversion capacity;
5. historical identity;
6. modern datasheet-role projection.

Current rules never overwrite an older physical build.
