## Reconstruction hypotheses — not promoted to collection fact

Two arithmetic patterns may help explain the later order.

### Hypothesis A — completing three flamer groups

The old roster had three hand-flamer groups of 8 bodies.

The newly found **6 bodies** are exactly enough to turn:

**8 + 8 + 8 → 10 + 10 + 10**

The later order also contains **10 additional hand flamers**, so there are enough extra flamer components to equip those six added bodies and retain four spares.

This is a strong numerical fit, but it is not treated as confirmed intent.

### Hypothesis B — stable 5/10-model icon-bearing units

Current 11E Acolyte units use 5- or 10-model sizes and may take one cult icon per unit.

The collection has **45 bodies** and **7 recorded icon/banner components**.

If all 45 bodies were intended to be partitioned into exactly seven icon-bearing units using only 5- and 10-model sizes, the only arithmetic solution is:

- **five 5-model units**
- **two 10-model units**

This resembles the user's memory of many stable five-model units plus one or more larger groups, but remains a planning hypothesis rather than a physical fact.
