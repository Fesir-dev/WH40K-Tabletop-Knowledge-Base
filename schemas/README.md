# Schemas

The legacy project used structured JSON extensively but did not provide a complete formal schema layer.

The new repository will introduce explicit schemas for:

1. source registry entries;
2. rules snapshots;
3. faction/unit semantics;
4. points snapshots;
5. collection body pools;
6. shared component/weapon pools;
7. physical allocation constraints;
8. roster snapshots;
9. paint/material inventory;
10. migration records.

Schema evolution must be versioned and backwards-aware.
