# Competitive analytics

This domain stores **dated evidence about how Warhammer 40,000 is played**, not normative rules.

It supports:

- faction/detachment performance;
- matchup and Force Disposition analysis;
- tournament roster composition;
- unit take rates;
- mathhammer/model outputs;
- expert competitive interpretation;
- collection-aware roster recommendations.

Key contracts:

- `ANALYTICS_SOURCE_MATRIX.md` / `.json`
- `ROSTER_RECOMMENDATION_EVIDENCE_MODEL.md`
- `roster_recommendation_evidence_model.json`

Historical analytics snapshots must be immutable and tied to a rules/points patch.
