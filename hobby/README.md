# Hobby knowledge

Reserved for the user's physical hobby resources and workflows.

Planned domains:

- `paints/` — owned paints, brands, ranges, quantities/status;
- `recipes/` — repeatable painting recipes and color schemes;
- `basing/` — basing materials and recipes;
- `tools/` — brushes, airbrush, cutters, drills, magnets and other tools;
- `materials/` — primers, varnishes, thinners, putties, glues, decals and consumables.

Paint/material inventory should use the same provenance principles as miniature inventory: observed ownership is separate from external product catalogs.
